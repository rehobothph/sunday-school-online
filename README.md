# Online Sunday School - Rehoboth Prayer House ⛪

Official Sunday School Portal for **Rehoboth Prayer House, Madapura, Karnataka**.

## 🌟 Features / ಮುಖ್ಯ ಲಕ್ಷಣಗಳು
- **Online Registration:** Easy Google Forms integration for new student enrollment.
- **User Authentication:** Integrated Sign Up & Login modal interfaces.
- **Bible Verses for Kids:** Inspiring Bible memory verses in Kannada.
- **Google Classroom Integration:** Class code (`d4gitf5e`) & Direct App download links for Android & iOS.
- **Study Resources:** Direct links to PPT presentations, JESUS Film (Kannada), Bible study articles, and ICM Audio Lessons.
- **Church Contact:** Direct buttons for Calling, WhatsApp, and Emailing Pastor Ramesh C.

## 🛠️ Technology Used
- **HTML5**
- **CSS3**
- **JavaScript (ES6)**
- **FontAwesome Icons**
